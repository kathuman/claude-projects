Android app Tap Start sensors and allow what the browser asks for. Everything stays on this phone unless you connect it to a computer. The camera and microphone start from their own cards.

Stream to a computer: open this page on the computer, choose Computer view, then scan its QR code with this phone or type its code here. With a cable instead, run the USB bridge on the computer and tap USB cable.

  1. On the phone, switch on USB debugging: Settings › About phone › tap Build number seven times, then Settings › System › Developer options › USB debugging.
  2. On this computer, install Android platform-tools (adb) and Node.js, download sensor-deck-usb.js and run node sensor-deck-usb.js.
  3. Plug the phone in and accept Allow USB debugging on it.
  4. On the phone, open Sensor Deck (the page or the app), tap USB cable, then Start sensors.

The Android app

Browsers only let a page read some sensors. The Sensor Deck app runs this same page and adds the rest, read through Android's SensorManager: the barometer, the battery's and the air's temperature, humidity, proximity, the hardware step counter, a fingerprint check (Android only ever says whether a fingerprint matched, never the print itself) and any other sensor the phone lists. Everything else works as here, including recording and the computer view.

  1. On the phone, download sensor-deck.apk (Android 7 or later, 64-bit ARM: practically every phone since 2017).
  2. Open it. Android asks to allow installing from your browser the first time: allow it, then install.
  3. Open Sensor Deck and tap Start sensors.

The app is not on Google Play, so Android warns about an unknown app; its source is in phone-sensors/android. Phones differ: few have an air thermometer or a hygrometer, and the cards say which sensors yours lacks.
