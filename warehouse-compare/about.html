About the app

Warehouse Compare

Three ways to pick orders, compared on equal terms. Racks that robots bring to the pickers, a semicircle around the picking points, and a classic rectangle each get the same SKUs, the same orders and the same number of storage locations. Each is built on the smallest floor that holds them, and judged by the same measures.

What it does

  • Moving racks (WH-A)Robots carry racks to fixed picking stations and put them back where a put-away policy says, so busy racks can move towards the pickers. A simulation of every robot, rack and station sizes the stations and the robot fleet.
  • Semicircle and rectangle (WH-B, WH-C)Pickers walk the shortest tour for each order. The rectangle is the Warehouse Model's own layout; the semicircle has radial or concentric rows.
  • Compares on equal termsFloor area, picker time, pickers and robots needed, build cost and cost per order line, side by side, each with the steps that produced it.
  • Shows what changes the answerAn animation of the peak hour in all three, sensitivity sweeps, and a demand shock that moves popularity to other SKUs.

How it is built

Every layout becomes a travel network, curved aisles included, and every distance is a shortest path through it. The rectangle reproduces the Warehouse Model's travel formulas exactly. The semicircle's distances match closed forms, and its racks are proven not to overlap or block an aisle. The moving-rack simulation is checked against a cycle worked out by hand. Each of these checks was itself tested by breaking the code on purpose. Everything runs in your browser.
