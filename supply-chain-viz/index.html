Seeing a supply chain network

Network design asks where to make things, where to hold them, and how they should flow to customers at the lowest total cost for a target service level. Every one of those questions has a picture that makes the answer obvious — and a wrong picture that hides it.

This is a working library of those pictures, ordered from the plots you'd put in a status deck to the analyses that actually drive a network study. Every example runs on the same small synthetic network — 5 suppliers, 3 plants, 5 DCs, 12 demand regions — so you can watch the same facts get re-encoded as the questions get harder.
