Validation

The engine run on cases whose answer is known independently: a hand calculation, the definition of a tax rule, or a brute-force search. These run live in your browser, from the same code the configurator uses, every time this page opens.

Firmware

Every program the configurator can generate, about 200 combinations of controller, motor driver, encoders, behaviours, link and arm, is compiled on every change with arduino-cli for the Uno, the Nano and the ESP32, exactly as the Arduino IDE does. A build fails on any compiler warning in the generated code.

Prices

A weekly job follows every product link and lists prices older than 90 days.

Measured builds

The models are first-order engineering models with safety factors. The real test is a built robot: on the main page, "Built it? Compare your robot with the model" sets your measurements beside the predictions and can send them in, which is how the models will be calibrated.
