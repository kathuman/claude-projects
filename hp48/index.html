An HP 48GX, emulated from its CPU up

This emulator rebuilds the 48GX's hardware in JavaScript: the Saturn CPU, the memory controller, the timers, the display and the keyboard. It then runs the calculator's own firmware. The CPU is written from the Saturn documentation, not copied from another emulator. It is checked against a separate disassembler and against the real ROM.

You bring the ROM

The ROM is HP's copyrighted firmware, so it is not included and never will be. When the calculator page is ready, you will load a ROM file you own: dumped from your own calculator or obtained at your own discretion. It stays in your browser and is never uploaded. The emulator targets the 48GX, revision R.

How it is checked

About 190 automated checks cover every instruction family and the memory controller's configuration protocol. They also cover the timers, the keyboard lines and the display registers. A fuzz test decodes 20,000 random instructions with both the CPU and the disassembler. Boot tests run the real ROM locally and compare screens by hash. The real firmware exposed two mistakes the unit tests had shared, and both are fixed. Details are in the README.
