    Run

    Supply chain toolkit

    Seven programs for inventory and flow, installed in a directory SCM on the calculator and shown on its menu keys. The calculator types them on its own keyboard, and each answer is checked against a reference calculation.

    Memory

    The calculator is kept in this browser and carries on where you left it, with its clock still right. Save it to a file to keep a copy or move it to another computer.

    Type a program

    Paste a program or any text and the calculator types it on its own keyboard, into its command line. Plain text («, », → …) and HP's ASCII transfer format (\<< \-> …) both work. You can also drop a text file on the calculator.
