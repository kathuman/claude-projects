# Cburnett chess pieces

The 12 SVGs here are the standard chess piece set by **Colin M.L. Burnett ("Cburnett")**,
downloaded unmodified from Wikimedia Commons (`File:Chess_klt45.svg` … `File:Chess_pdt45.svg`),
renamed to `wK.svg` … `bP.svg`.
